Agent d’impression

Pour créer le fichier d’impression directement depuis l’atelier, installez une fois l’agent sur ce PC. Il travaille en arrière-plan : aucune fenêtre ne s’ouvre, rien à régler.

  1. Téléchargez Installer-Atelier.cmd.
  2. Ouvrez-le (double-clic). Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires puis Exécuter quand même.
  3. Une fenêtre noire s’ouvre : attendez « C’est prêt ! » (1 à 3 minutes), fermez-la et revenez ici.

Si le navigateur demande d’autoriser l’accès aux appareils du réseau local, répondez Autoriser. En attendant, le bouton .3mf permet toujours de passer par un slicer.
